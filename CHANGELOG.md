# Changelog

All notable changes to this project will be documented in this file.

## [0.9.4-beta] - 2026-11-19

### Added
- Extended vanilla coordinate integration to 2D coordinate arguments (`ColumnPosArgument` and `Vec2Argument`), enabling waypoint names in commands like `/forceload add Base`, `/spawnpoint`, and `/spreadplayers`.
- Added `/coords near` to quickly locate the closest saved waypoint in the player's current dimension.
- Added `/coords search <query>` to filter waypoints by name or dimension.
- Added `/coords rename <old_name> <new_name>` to rename waypoints in-place while preserving insertion order.
- Added optional `<dimension>` parameter to `/coords add` and `/coords replace` when specifying explicit coordinates.
- Added click-to-teleport command suggestion when clicking a waypoint's name in `/coords recall`, `/coords list`, `/coords near`, and `/coords search`.

### Fixed
- Updated `WaypointsSyncPayload` in `ScribeNetworking` to use `StreamCodec.composite` and `ByteBufCodecs.list()` for compatibility with Minecraft 26.3 (which removed `FriendlyByteBuf.readList` and `FriendlyByteBuf.writeCollection`).
- Fixed singleplayer integrated server race condition where `ClientPlayConnectionEvents.DISCONNECT` prematurely cleared `CoordinateStorage` before `SERVER_STOPPED` finished world shutdown.
- Fixed `/coords replace` click suggestion omitting the target dimension when attempting to add a duplicate waypoint name.

### Changed
- Optimized `CoordinateStorage.names()` and `CoordinateStorage.all()` with lock-free volatile immutable snapshots, eliminating list and stream allocations on every chat keystroke.
- Short-circuited vanilla coordinate parser validation in `CoordinateSuggestionMixin` when typing non-numeric waypoint prefixes, avoiding unnecessary exception throwing during tab-completion.
- Upgraded `CoordinateSuggestionMixin` to use `SharedSuggestionProvider.matchesSubStr` for word-segment matching (e.g., matching `nether_portal` by typing `portal`).
- Replaced regex `String.split("\\s+")` in `CoordinateEntry.fromFileLine` with a zero-regex character scanner for faster file loading.

## [0.9.3-beta] - 2026-09-03

### Added
- Added client-server waypoint synchronization via Fabric Networking (`CustomPayload`) to support autocompletion and syntax validation in multiplayer.
- Added pagination to `/coords list [page]` (8 waypoints per page) with interactive `[< Prev]` and `[Next >]` buttons.
- Added automatic `.bak` backup protection in `CoordinateStorage` if writing after an initial file load failure.
- Added autogenerated explanatory header to `saved_coords.txt`.
- Added audit logging of waypoint additions, replacements, and deletions.
- Added direct `load(Path)` overload and comprehensive JUnit 5 disk I/O test suite.

### Fixed
- Fixed `/coords replace` suggestion embedding player's future location if they moved before clicking; now always records the exact coordinates.
- Fixed chat packet flooding in `/coords list` by consolidating output into a single formatted component.

## [0.9.2-beta] - 2026-08-14

### Fixed
- Fixed command alias execution failing when running `/coordinates` or `/scribe` without subcommands.
- Fixed waypoint saving in unloaded chunks by avoiding forced chunk-loading checks.
- Fixed command execution from server console and command blocks when saving waypoints with explicit coordinates.
- Fixed race conditions during concurrent tab-completion and waypoint modifications.

### Changed
- Automatically clear in-memory coordinate data on server shutdown.
- Optimized tab-completion suggestions and cleaned up redundant command formatting.
- Added automated unit test suite.

## [0.9.1.1-beta] - 2026-08-04

### Changed
- Removed redundant `[other dimension]` text from `/coords list` and `/coords recall` commands.

## [0.9.1-beta] - 2026-07-08

### Added
- Display waypoint distance (in meters) and dimension warning when viewing coordinates in `/coords list` and `/coords recall`.

### Changed
- Atomic file saving for `saved_coords.txt` with temporary file fallback to prevent data loss on server crash.
- Optimized Brigadier command tree registration and redirection for command aliases (`/coordinates`, `/scribe`).
- Updated ModMenu quick guide descriptions and standardized internal documentation in English.
